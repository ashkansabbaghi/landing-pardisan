# زمینهٔ ثابت لندینگ پردیسان

مخاطب تصمیم: **اشکان**. زبان خروجی هیئت: **فارسی**. لحن: فنی و اجرایی.

## محصول

وب‌سایت چندصفحه‌ای **مدرسه پردیسان** در کرج. فارسی، RTL، ظاهر شیشه‌ای معماری.

هدف کسب‌وکار: اعتماد والدین، تمایز دو مقطع/دو شعبه، و رساندن مخاطب به **تماس / ثبت‌نام**.

| مسیر | محتوا |
| --- | --- |
| `/` | صفحه اصلی |
| `/about` | درباره ما |
| `/middle` | متوسطه اول — شعبه ۱ (باغستان) |
| `/high` | متوسطه دوم — شعبه ۲ (عظیمیه) |
| `/elite` | نخبه‌ها |
| `/teachers` | معلمان |
| `/staff` | کادر |
| `/locations` | شعبه‌ها و آدرس |
| `/register` | تماس و پذیرش |

محتوای نمونه (نام‌ها، آدرس‌ها، تلفن‌ها) در README صریحاً **ساختگی** است تا مدرسه محتوای واقعی بدهد.

## فنی

- Nuxt 4، Vue 3، Tailwind 4، TypeScript، `@nuxt/image`، `@nuxtjs/sitemap`
- دامنهٔ پیکربندی‌شده: `https://pardisan-novin.ir`
- انتشار ایستا با GitHub Actions روی GitHub Pages؛ `npm run generate` کلید تلگرام نمی‌خواهد
- فرم ثبت‌نام: `server/api/register.post.ts` + ربات تلگرام برای intake محتوا (`npm run intake:telegram`)
- CSP و هدر امنیتی در `nuxt.config.ts`
- تصاویر محوطه در `/images/campus/`

هزینهٔ واقعی غالب: **وقت اشکان**، نه هاست. Pages رایگان است. دامنه، عکس واقعی، و نگهداری ربات جدا حساب می‌شوند.

## خط قرمز

عکس و دادهٔ دانش‌آموز خردسال، شمارهٔ واقعی قبل از تأیید مدرسه، و قول آموزشی که محتوایش ساختگی است.
